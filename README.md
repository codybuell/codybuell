# Cody Buell

Full stack engineer. I build the software, the infrastructure it runs on,
and the teams that keep it going.

I have built and led DevOps teams, helped companies grow from nothing, and
spent years on site at NASA's Goddard Space Flight Center building the
systems that supported the science.

These days I run [Company Robot](https://companyrobot.io), an independent
practice that usually goes one of three ways:

- **A dev team in one person.** You have something to build and no one to
  build it. I take it from idea to running in production.
- **A CTO on call.** You have a team, or you are about to hire one. I make
  the architecture calls and unblock the hard parts.
- **Building it yourself, properly.** AI means one person can ship what
  used to take a team, but only on a real foundation. I set you up with
  one, then teach you to work in it.
